# chaeokeefe.com

Personal site, built with [Astro](https://astro.build/) and Tailwind CSS 4.

The design system (layout, components, typography, color tokens) is adapted from
the [Maria](https://github.com/xocothemes/maria) Astro theme by Andrei Alba, used
under the MIT License — see [`THIRD_PARTY_LICENSES.md`](THIRD_PARTY_LICENSES.md).

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deployment

Pushes to `main` build and deploy automatically via
[`.github/workflows/deploy.yml`](.github/workflows/deploy.yml) to GitHub Pages.
